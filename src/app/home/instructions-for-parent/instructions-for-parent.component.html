FAQ's

What if my child doesn't have the app downloaded yet?

Your child will need to download the app first. You can share the download link along with the family code.

Can I add multiple children to the same family?

Yes, you can add multiple children to your family using the same family code.

What if the family code stops working or expires?

Family codes don't expire, but you can generate a new one if needed from your family settings.

What if I want to join someone else's family instead of creating my own?

You can choose to join an existing family instead of creating a new one in the next step.
