FAQ's

Should I create a new family or join an existing one?

Create a new family if you're the first parent setting up the account. Join an existing family if another parent has already created one and shared the family code with you.

What happens after I create my family?

You'll receive a unique family code and QR code that you can share with your children or partner. They can use this code to join your family and sync their progress.

Can I change my family name later?

Yes, you can change your family name anytime from the family settings page in your profile.

What if I accidentally create a family when I meant to join one?

No problem! You can leave the family you created and join the correct one using the family code. Contact support if you need help with this process.
What if I don't have the family code or QR yet?

Ask the family creator (usually the other parent) to share the family code or QR code with you. They can find this in their family settings or after creating the family.

How do I scan the QR code if my camera isn't working?

If the QR scanner isn't working, you can manually enter the family code instead. The family code is usually 6-8 characters long and contains letters and numbers.

What happens if the code is wrong or expired?

If you enter an incorrect code, you'll see an error message. Family codes don't expire, but make sure you're entering the exact code provided by the family creator. Double-check for any typos.

Can I use the app without linking right now?

Yes, you can continue without joining a family and set up individual tracking. You can always join a family later from your profile settings.
How do I share this code with my child?

You can share the family code directly by copying it, or use the QR code feature. Your child can scan the QR code or enter the family code in their app to join your family.

Does the family code expire or stop working?

No, family codes don't expire. However, you can generate a new code anytime from your family settings if needed for security reasons.

What if my child enters the wrong code or it doesn't work?

Make sure your child enters the code exactly as shown. If issues persist, try generating a new family code from settings or use the QR code instead.

Can multiple children use the same family code?

Yes! Multiple children can join the same family using this code. Each child will have their own progress tracking within the family.
